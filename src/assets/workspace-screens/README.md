# Prints do CALI Workspace usados na Landing Page

Envie aqui os prints originais em PNG, JPG, JPEG ou WEBP.

Não precisa renomear os arquivos. A Landing Page detecta automaticamente todas as imagens desta pasta. Quando existir pelo menos um arquivo aqui, estes prints passam a substituir automaticamente os arquivos antigos de baixa resolução.

Para melhor nitidez, prefira PNG original, capturado diretamente da tela, sem redimensionar e sem passar por WhatsApp.
