# Fotos do carrossel da Landing Page

Envie aqui as fotos originais em JPG, JPEG, PNG ou WEBP.

Não precisa renomear os arquivos. A Landing Page detecta automaticamente todas as imagens desta pasta e usa a ordem alfabética dos nomes apenas para definir a sequência do carrossel.

Para preservar qualidade, prefira os arquivos originais e evite prints, imagens reenviadas por WhatsApp ou arquivos já comprimidos.
